# Air Bersih untuk Semua

Website edukasi bertema SDG 6: Clean Water and Sanitation, dibuat sebagai proyek UTS mata kuliah Pemrograman Web.

## Struktur Proyek

```text
air-bersih-untuk-semua/
├── index.html
├── edukasi.html
├── tips.html
├── artikel.html
├── tentang.html
├── css/
│   └── style.css
├── images/
│   ├── hero-water.svg
│   ├── river-pollution.svg
│   ├── clean-water.svg
│   ├── water-saving.svg
│   └── sanitation.svg
└── README.md
```

## Fitur Utama

- Tampilan modern dan responsif untuk desktop, tablet, dan smartphone
- Navigasi antar halaman yang konsisten
- Konten edukasi tentang air bersih, sanitasi, dan SDG 6
- Tips dan aksi sederhana untuk masyarakat
- Artikel informatif dengan sumber referensi yang relevan
- Desain menggunakan HTML5 dan CSS3 murni tanpa framework

## Cara Menjalankan

Buka file `index.html` di browser atau jalankan dengan perangkat lokal untuk melihat website.
